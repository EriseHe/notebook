      1.2 Functional Analysis

      This section covers basic concepts in functional analysis, such as Lebesgue Spaces, Distributions, Sobolev Spaces

      Since a PDE can be viewed as an operator mapping data to solution, numeric replaces the infinite-dimensional space by a finite-dimensional subspace, so we need:

      • notions of size (norm),
      • notions of closeness (metric),
      • notions of limits (completeness),
      • notions of orthogonality/projection (Hilbert),
      • and generalized derivatives (distributions) to make sense of weak solutions.

      In PDE, we need the weak (variational) formulation because the classical formulation asks for derivatives that often don’t exist, and because numerics (especially FEM) naturally lives in an integral/inner-product world. In the following notes, we will build the language used to write PDEs in a weak/variational form, and use them to analyze numerical methods (FEM, DG, FV) later.

      0.1 Basics of Functional Analysis

      In previous section, we think of PDE as a “problem operator” \[ P:\ d \longmapsto u = P(d), \] where \(d\) is the data (forcing term, boundary values, initial condition, coefficients) and \(u\) is the solution. Functional analysis provides the right spaces \(X\) where this mapping is well-defined and stable.

      Definition 1.2.1Functional

      A functional is \(\mathcal{F}(\cdot): X \to \mathbb{R}\). Let \(f(x), g(x) \in X\). A functional is linear if \[ \mathcal{F}(\lambda f(x) + \mu g(x)) = \lambda \mathcal{F}(f(x)) + \mu \mathcal{F}(g(x)) \]

      Interpretation. A functional takes a function and returns a number (think: “measurement”). Linearity means the measurement respects superposition.

      Example 1.2.2A functional

      For example, \[ \int_a^b f(x)\,dx \] is a functional.

      Why it matters. Weak formulations are built out of integrals of the solution against test functions; those are functionals.

      Definition 1.2.3Form

      A form is \(a(\cdot,\cdot): X \times X \to \mathbb{R}\), where \(f, g \in X\). A form is bilinear if

      • \(a(\lambda f_1 + \mu f_2, g) = \lambda a(f_1,g) + \mu a(f_2,g)\)
      • \(a(f, \lambda g_1 + \mu g_2) = \lambda a(f,g_1) + \mu a(f,g_2)\)

      Remark. A bilinear form takes two functions and returns a number.

      Definition 1.2.4Space

      A space is a set with operations defined. If \(X\) is a space, then

      • \(f \in X \Longrightarrow \lambda f \in X\)
      • \(f,g \in X \Longrightarrow \lambda f + \mu g \in X\)

      Remark. This is the “closed under linear combinations” property (vector space idea).
      It’s needed so we can add trial functions, scale solutions, etc.

      0.2 Metrics, completeness, and norms

      0.2.1 Why do we need a distance?

      To talk about convergence of numerical methods, we need a notion of “\(u_h \to u\)”. That requires a distance or metric, and usually we obtain it from a norm.

      Definition 1.2.5Distance

      A distance is \(d(\cdot,\cdot): X \times X \to \mathbb{R}\) such that \(\forall\, f,g,w \in X\)

      • \(d(f,g) = d(g,f)\) [symmetry]
      • \(d(f,g) \ge 0\) and \(d(f,g)=0 \Longleftrightarrow f=g\)
      • \(d(f,g) \le d(f,w) + d(w,g)\) [triangle inequality]

      A space with a distance is a metric space.

      Definition 1.2.6Completeness

      Let \((X,d)\) be a metric space. Let \(f_n\) be a sequence in \(X\) and \(f\) be a candidate limit.

      1. The sequence is convergent if \(d(f_n,f)\to 0\) as \(n\to +\infty\)
      2. The sequence is Cauchy if \(d(f_n,f_m)\to 0\) as \(n,m\to +\infty\)

      In general, \(1 \Longrightarrow 2\), but \(2 \not\Longrightarrow 1\). Indeed, \[ d(f_n,f_m) \le d(f_n,f) + d(f,f_m) \] by triangle inequality.

      If in a metric space, \(1 \Longleftrightarrow 2\), then the metric space is complete.

      Why completeness matters in PDE. If a method produces a Cauchy sequence of approximations, completeness guarantees a limit exists in the same space. That’s crucial for existence arguments and for convergence proofs.

      Definition 1.2.7Norm

      A norm is \(\|\cdot\|_X: X \to \mathbb{R}\) such that

      • \(\|f\|_X \ge 0\) and \(\|f\|_X = 0 \Longleftrightarrow f=0\)
      • \(\|\lambda f\|_X = \lambda \|f\|_X\)
      • \(\|f+g\|_X \le \|f\|_X + \|g\|_X\)

      A space is normed if a norm is defined.
      A normed space is also a metric space: \[ d(f,g) = \|f-g\|_X \]

      Comment. Most numerical error estimates are statements like \(\|u-u_h\|_X \le C h^p\).
      That only makes sense after we choose a norm \(\|\cdot\|_X\).

      Definition 1.2.8Banach Space

      A Banach space is a complete normed space.

      Comment. Banach spaces are the natural setting for fixed-point theorems and stability results.

      0.3 Inner products, Hilbert spaces, and orthogonality

      0.3.1 Why inner products show up in FEM

      Galerkin methods are built from orthogonality conditions like \((u-u_h, v_h)=0\).
      That requires an inner product structure.

      Definition 1.2.9Scalar Product

      \((\cdot,\cdot)_X: X \times X \to \mathbb{R}\) is a symmetric bilinear form such that

      • \((f,g)_X = (g,f)_X\)
      • \((f,f)_X \ge 0\) and \((f,f)_X = 0 \Longleftrightarrow f=0\)
      • \(\left|(f_1,f_2)_X\right| \le (f_1,f_1)_X^{1/2}(f_2,f_2)_X^{1/2}\) [Cauchy-Schwarz Inequality]

      A scalar product induces a norm: \[ \|f\|_X^2 = (f,f)_X \] So, a space with a scalar product is automatically normed.

      Key point. Inner product \(\Rightarrow\) norm \(\Rightarrow\) metric \(\Rightarrow\) talk about convergence.

      0.3.2 Example 1.2.10

      Example 1.2.10A standard estimate from the scalar product

      \[ \begin{aligned} (f_1+f_2,f_1+f_2)_X &= (f_1,f_1)_X + 2(f_1,f_2)_X + (f_2,f_2)_X \\ &\le \|f_1\|_X^2 + 2\|f_1\|_X\|f_2\|_X + \|f_2\|_X^2 \\ &= (\|f_1\|_X + \|f_2\|_X)^2 \end{aligned} \] (Here the inequality step uses Cauchy–Schwarz on \((f_1,f_2)_X\).) Taking square-roots yields \(\|f_1+f_2\|_X \le \|f_1+f_2\|_X+\|f_2\|_X\).

      Note (typo fix in words only). The last line should read: \[ \|f_1+f_2\|_X \le \|f_1\|_X + \|f_2\|_X, \] which is exactly the triangle inequality for the induced norm.

      Definition 1.2.11Hilbert Space

      A Hilbert space is a Banach space equipped with a scalar product.

      Practical takeaway. Hilbert = “complete + inner product”.
      Most FEM theory lives in Hilbert spaces (especially \(L^2\), \(H^1\), \(H_0^1\)).

      Definition 1.2.12Orthogonality

      The angle between two functions is defined as \[ \angle(f_1,f_2):\ \cos(\varphi) = \frac{(f_1,f_2)}{\|f_1\|\|f_2\|} = \frac{(f_1,f_2)}{(f_1,f_1)^{1/2}(f_2,f_2)^{1/2}} \] Two functions are orthogonal to each other \(\Longleftrightarrow (f,g)=0\). We denote \(f \perp g\).

      Interpretation. Orthogonality means “no component in that direction,” just like vectors in \(\mathbb{R}^n\).

      0.4 Orthogonal Projection (Galerkin principle)

      When we approximate in a subspace \(X_L\), the best approximation is obtained by orthogonal projection (in a Hilbert space). This is the geometric heart of the Galerkin method.

      0.4.1 Find the Best Approximation

      Let \(X_L \subset X\), where \(X_L\) is “small.” \(X_L\) and \(X\) are both Hilbert spaces.

      We want to find the best approximation \(f_L\) of \(f\) in \(X_L\). So, we need to find \(f_L\) s.t. \[ (f - f_L, v_L) = 0 \quad \forall\, v_L \in X_L \]

      What this condition means.

      • \(f-f_L\) is the error.
      • The condition says the error is orthogonal to the whole approximation space \(X_L\).
      • This uniquely characterizes \(f_L\) as the orthogonal projection of \(f\) onto \(X_L\).

      This is an extension of the Pythagorean Theorem. If \(g_L \in X_L\): \[ \begin{aligned} \|f-g_L\|^2 &= (f-g_L,f-g_L) \\ &= (f-f_L + f_L-g_L,\ f-f_L + f_L-g_L) \\ &= \|f-f_L\|^2 + 2(f-f_L,f_L-g_L) + \|f_L-g_L\|^2 \\ &= \|f-f_L\|^2 + \underbrace{2(f-f_L,f_L-g_L)}_{=0,\ \text{orthogonality}} + \|f_L-g_L\|^2 \\ &= \|f-f_L\|^2 + \|f_L-g_L\|^2 \\ &\ge \|f-f_L\|^2 \end{aligned} \]

      Conclusion. Among all \(g_L \in X_L\), the minimizer of \(\|f-g_L\|\) is \(f_L\).
      So “best approximation” = “orthogonal projection”.

      0.5 Lebesgue Integration and \(L^p\) spaces

      0.5.1 Why we switch to \(L^p\)

      Many PDE solutions are not classically smooth. We need spaces that:

      • allow functions with limited regularity,
      • still make integrals meaningful,
      • provide norms used in stability/error estimates.

      Definition 1.2.13\(L^p\) Spaces

      \[ L^p(a,b) = \left\{\, f:\ (L)\int_a^b f^p\,dx < +\infty \right\}, \quad \text{with } p=1,2,\ldots,\in \mathbb{N} \] Here, \((L)\) indicates that the integration is done in Lebesgue sense. \(L^p(a,b)\) is the collection of functions that can be integrated in interval \((a,b)\) in the Lebesgue sense without blowing up.

      These are Banach spaces with the norm \[ \|f\|_p = \left(\int_a^b |f|^p\,dx\right)^{1/p} \]

      Interpretation.

      • \(L^1\): integrable functions (area under curve finite).
      • \(L^2\): square-integrable (energy finite) — the most common in PDE/FEM.

      Similarly, \[ L^\infty(a,b) = \left\{\, f:\ \text{bounded (up to all-measurable intervals) in }(a,b)\right\} \] is also a Banach space with norm \[ \|f\|_\infty = \max_{(a,b)} |f| \]

      Comment. Strictly speaking, \(L^\infty\) uses the essential supremum (ignores measure-zero sets), but the above matches the typical intuition.

      Specially, \(L^2(a,b)\) or \(L^2(\Omega)\) with \(\Omega \subset \mathbb{R}\) is a Hilbert space: \[ \begin{aligned} (f,g) &= \int_a^b f g\,dx \\ \|f\|_2 &= \left(\int_a^b f^2\,dx\right)^{1/2} = (f,f)^{1/2} \end{aligned} \]

      Why \(L^2\) is special. It has an inner product, so we get orthogonality/projection tools.

      Definition 1.2.14Conjugate Spaces

      \(L^p\) and \(L^q\) are called conjugated spaces if we have the function \(f\in L^p(a,b)\) and \(g\in L^q(a,b)\) with \[ \frac{1}{p}+\frac{1}{q}=1 \] We then have \[ (L)\int_a^b f g\,dx < +\infty \quad \text{or}\quad f g \in L^1(a,b) \]

      Context. This is the setup for Hölder’s inequality and for defining dual pairings \(L^q = (L^p)'\) (for \(1<p<\infty\)).

      Remark 1.2.14\(L^2\) is conjugate with itself

      We have \[ |(f,g)_{L^2}| \le \|f\|_2\|g\|_2 \]

      Comment. This is exactly Cauchy–Schwarz in \(L^2\).

      0.6 Distributions and weak derivatives

      0.6.1 Motivation: derivatives that still exist when functions are not smooth

      In PDE, solutions may have jumps, corners, or only be \(L^2\).
      Classical derivatives may not exist, but we still want a “derivative” compatible with integration by parts (weak form).
      Distributions are the clean framework.

      Definition 1.2.15Dual Spaces

      The set of linear bounded functionals obtained on a space \(X\) is per se a functional space, that we call dual space and denote as \(X'\) \[ X' = \left\{\mathcal{F}(f)\ \text{for } f\in X,\ \text{linear and s.t.}\ \|\mathcal{F}(f)\|\le c\|f\|_X\right\} \]

      Interpretation. Elements of \(X'\) are “bounded measurements” on \(X\).
      Boundedness (\(\|\mathcal{F}(f)\|\le c\|f\|_X\)) is what makes the functional continuous and stable.

      Theorem 1.2.16Riesz Representation Theorem

      In \(L^2\), the dual of \(L^2\) is isometric to \(L^2\).
      (This means that any linear and continuous functional in \(L^2\) corresponds to an element within \(L^2\) itself.)

      Practical meaning. Every bounded linear functional on \(L^2\) can be written as an \(L^2\) inner product with some \(g\in L^2\): \[ \mathcal{F}(f) = (g,f)_{L^2}. \] (You don’t need the full proof here; you use it later when deriving weak forms.)

      Definition 1.2.17Support

      The support of a function is where the function \(\ne 0\) on the interval or region of the domain of definition. In particular, if the support is closed and bounded region, we say the function has compact support.

      Why compact support matters. It kills boundary terms in integration by parts (no “leakage” at infinity).

      Definition 1.2.18The Space \(\mathcal{D}\)

      \[ \mathcal{D} = \{\text{functions in } C^\infty(\mathbb{R}^n)\ (n\ge 1)\ \text{with compact support}\} \]

      The dual space of \(\mathcal{D}\), \(\mathcal{D}'\) is defined in the following notion: \[ \mathcal{D}':\ \langle T,f\rangle_{\mathcal{D}} \in \mathbb{R},\ \text{where } T\in\mathcal{D}'\ \text{is linear and continuous and } f\in\mathcal{D} \]

      \(T\) to be continuous is defined in the following sense: Let \(\mathrm{supp}(f_n)\subseteq K\) and \(f_n\to f\) and \(n\to\infty\). Then, \(T\) is continuous if \[ \langle T,f_n\rangle \to \langle T,f\rangle \]

      Interpretation.

      • \(\mathcal{D}\) = smooth test functions that vanish outside a bounded set.
      • \(\mathcal{D}'\) = all continuous linear functionals acting on \(\mathcal{D}\). These are the “generalized functions”.

      Example 1.2.19A distribution coming from a step function

      Let \(H(x)\) be the step function \[ H(x)= \begin{cases} 0 & \text{for } x\le 0 \\ 1 & \text{for } x>0 \end{cases} \] Then \[ \langle T,f\rangle = \int_{-\infty}^{+\infty} H f\,dx = \int_0^{+\infty} f\,dx \] The functional \(\langle T_0,f\rangle = f(0)\) belongs to \(\mathcal{D}'\) \[ |\langle T_0,f\rangle| \le \max_{x\in\mathbb{R}} |f(x)| \]

      Comment. Two important examples of distributions:

      • \(f \mapsto \int_0^\infty f\) (integration against a possibly discontinuous function \(H\)),
      • \(f \mapsto f(0)\) (evaluation at a point), which is not continuous on many \(L^p\) spaces but is meaningful on \(\mathcal{D}\).

      Definition 1.2.20Distributions

      The objects of \(\mathcal{D}'\) are called distributions or generalized functions.

      0.7 Weak derivative

      Theorem 1.2.21Distributional derivative identity

      \[ \langle T', f\rangle = -\langle T, f'\rangle \]

      Meaning. In the distribution sense, differentiating \(T\) is defined so that integration by parts is always true (with no boundary term due to compact support of \(f\)).

      Proof 1. Let \(g\in L^2\). Then \[ \begin{aligned} \langle g', f\rangle &= \int_{\mathbb{R}} g' f \\ &= \underbrace{\big[g f\big]_{-\infty}^{+\infty}}_{=0\ \text{since } f\ \text{has compact support}} - \int_{\mathbb{R}} g f' \\ &= -\langle g, f'\rangle \end{aligned} \] Note that \(\big[g f\big]_{-\infty}^{+\infty}=0\) because \(\lim_{x\to\infty} f=0\), and \(f\) has compact support.

      Example 1.2.22Differentiating the step function gives the Dirac impulse

      Consider \[ H(x)= \begin{cases} 0 & \text{for } x\le 0 \\ 1 & \text{for } x>0 \end{cases} \] Then, we can differentiate \(H\) \[ \begin{aligned} \int_{-\infty}^{+\infty} H' f &= -\int_{-\infty}^{+\infty} H f' \\ &= -\int_0^{+\infty} f' \\ &= -[f]_0^{+\infty} \\ &= f(0) \\ &= \langle T_0, f\rangle \end{aligned} \] \(T_0\) is called the Dirac-\(\delta\) and it is the mathematical description of an impulse. It is not a function in the traditional sense.

      Interpretation. \(H\) has a jump at \(0\). Its classical derivative is “zero everywhere except at 0”, which is captured by \(\delta\).

      Definition 1.2.23Dirac-\(\delta\)

      Dirac-\(\delta\) is the element in \(\mathcal{D}'\) such that \[ \langle \delta,f\rangle = f(0) \] We know that \(H'=\delta\).

      Theorem 1.2.24Inclusion into \(\mathcal{D}'\)

      \[ L^2 \subset \mathcal{D}' \]

      Comment. Any \(g\in L^2\) defines a distribution by \[ \langle g, f\rangle := \int_{\mathbb{R}} g f\,dx, \] so functions can be viewed as a special case of distributions.

      0.8 Sobolev spaces (the PDE workhorse)

      0.8.1 Measuring derivatives in \(L^2\)

      Sobolev spaces encode “how many derivatives exist in a weak sense” and how large they are. This is exactly what we need for:

      • weak formulations (existence/uniqueness),
      • regularity,
      • FEM error estimates.

      Definition 1.2.25Sobolev Spaces

      Space \(H^k(a,b)\) (or \(H^k(\Omega)\)) is the space of functions \(f\) s.t. it belongs to \(L^2\) together with all the derivatives up to the order \(k\) \[ H^k(a,b)=\left\{\, f\ \text{s.t.}\ f,f',\ldots,f^{(k)}\in L^2 = H^0 \right\} \]

      In multiple dimensions, the derivatives are all the derivatives of order \(k\) \[ \frac{\partial^{\alpha_1+\alpha_2+\cdots+\alpha_m} f}{\partial x_1^{\alpha_1}\partial x_2^{\alpha_2}\cdots \partial x_m^{\alpha_m}} \in L^2 \quad \text{with}\quad \sum_i \alpha_i = k \]

      These spaces are called Sobolev spaces. A more generalized definition \[ W^{k,p}=\left\{\, f\ \text{s.t.}\ f,f',\ldots,f^{(k)}\in L^p \right\} \] So, \(H^k = W^{k,2}\).

      Interpretation.

      • \(H^0 = L^2\).
      • \(H^1\) means \(f\in L^2\) and its weak derivative \(f'\in L^2\).
      • Higher \(k\) means more (weak) smoothness.

      Theorem 1.2.26Properties of \(H^k\)

      • \(H^k(a,b)\) is a Hilbert space with the scalar product \[ (f,g)_{H^k} = \sum_{i=0}^k (f^{(i)},g^{(i)})_{L^2} \]
      • \(H^1(a,b)\) has the norm \[ \|f\|_{H^1}^2 = \|f\|_{L^2}^2 + \|f'\|_{L^2}^2 \]
      • \(H^1 \subset L^2\). So, \[ \|f\|_{H^1}^2 \ge \|f\|_{L^2}^2 \]
      • In general, \[ H^{k+1} \subset H^k \subset \cdots \subset L^2 \]

      Why this nesting matters. More derivatives in \(L^2\) implies stronger control on the function, hence a “smaller” space.

      0.9 Boundary values and trace (why \(H^1\) is subtle)

      Definition 1.2.27Trace Operator

      Trace is an operator that maps a function in \(H^k\) to its value of the boundary, and, in general, reduces regularity. \[ \gamma:\ H^k(\Omega)\to H^{k-\frac{1}{2}}(\partial\Omega) \] is the (continuous) trace operator.

      Interpretation.

      • Functions in \(H^1(\Omega)\) may not be classically continuous, yet they have a well-defined boundary value in an appropriate sense.
      • The trace map “costs” a half-derivative of regularity.

      Definition 1.2.28The Space \(H_0^1\)

      The space \(H_0^1(\Omega)\) is the space of \(H^1\) functions with null trace on \(\partial\Omega\).

      Practical meaning. This is the natural space for homogeneous Dirichlet boundary conditions \(u=0\) on \(\partial\Omega\).

      0.10 Poincaré inequality and equivalent norms (the energy norm idea)

      Theorem 1.2.29Poincare Inequality

      \(\exists\, c>0\) s.t. for \(f\in H_0^1(\Omega)\) \[ \|f\|_{L^2} \le c\|\nabla f\|_{L^2} \] Therefore, \[ \begin{aligned} \|\nabla f\|_{L^2}^2 &\le \underbrace{\|f\|_{L^2}^2 + \|\nabla f\|_{L^2}^2}_{\|f\|_{H_0^1}^2} \le (1+c^2)\|\nabla f\|_{L^2}^2 \end{aligned} \] Hence, in \(H_0^1(\Omega)\), the norm of \(\nabla f\) in \(L^2\) and of \(f\) in \(H^1\) are equivalent. This is also true if the function has only a realization of the boundary (with measure \(>0\)) where it vanishes.

      Interpretation.

      • On \(H_0^1(\Omega)\), controlling \(\|\nabla f\|_{L^2}\) automatically controls \(\|f\|_{L^2}\).
      • So the “energy seminorm” \(\|\nabla f\|_{L^2}\) is effectively a full norm on \(H_0^1\).

      Remark 1.2.29Equivalent norms (abstract form)

      \[ \alpha\|u\|_F \le \|u\|_S \le \beta\|u\|_F \] implies that \(\|\cdot\|_F\) and \(\|\cdot\|_S\) are equivalent.

      Why we care. Equivalent norms define the same notion of convergence and stability. In PDE, we often switch between norms that are easier to estimate.

      Definition 1.2.30Dual of \(H_0^1\): \(H^{-1}\)

      \[ H_0^1 \subset L^2 \subset H^{-1} \]

      Interpretation.

      • \(H^{-1}\) is the dual space of \(H_0^1\) (in a standard identification).
      • Many PDE data terms (like forcing \(f\)) naturally live in \(H^{-1}\) when solutions live in \(H_0^1\).

      0.11 Space–time function spaces (for time-dependent PDE)

      0.11.1 Space-Time Functional Spaces

      For time-dependent problems, we have spaces that describe the two dependencies. For instance \[ L^p(0,T;H^k(\Omega)) \] is the space of functions s.t. \(\|f\|_{H^k}(t)\in L^p(0,T)\).

      Interpretation. You measure spatial regularity in \(H^k\), but that \(H^k\)-norm is a function of time, and you require it to be \(L^p\) in time.

      In short, we denote it as \(L^p(H^k)\). We will use \(L^2(H_0^1)\) and \(L^\infty(L^2)\).

      0.12 Sobolev embeddings (turn derivatives into integrability/continuity)

      Theorem 1.2.31Embedding Theorems

      If \(u\in H^s\) and \(\Omega\subset \mathbb{R}^n\)

      • \(0<2s<n:\ H^s\subset L^q\), where \(1\le q\le q^*=\dfrac{2n}{n-2s}\) [continuous embedding]
      • \(2s=n:\ H^s\subset L^q\ \ \forall\, q:\ 1\le q<+\infty\)
      • \(2s>n:\ H^s\subset C^0(\overline{\Omega})\)

      Also, \(H^s\subset C^n(\overline{\Omega})\) if \(s>n+\dfrac{n}{2}\).

      Interpretation.

      • Enough Sobolev regularity forces better integrability (\(L^q\)) and eventually continuity.
      • This is how “weak derivatives” translate into classical-looking properties.

      Remark 1.2.31A boundary constraint can break linear-space structure

      \(H^1(\Omega)=\{f\in H^1,\ f(\partial\Omega)=1\}\) is not a space. In fact \[ f_1,f_2\in H^1 \Longrightarrow f_1+f_2\notin H^1 \]

      Reason (intuition). If \(f_1|_{\partial\Omega}=1\) and \(f_2|_{\partial\Omega}=1\), then \((f_1+f_2)|_{\partial\Omega}=2\), violating the constraint. So affine constraints (fixed nonzero boundary values) create an affine set, not a vector space.
