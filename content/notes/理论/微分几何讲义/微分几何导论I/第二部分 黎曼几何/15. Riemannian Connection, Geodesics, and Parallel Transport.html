15. Riemannian Connection, Geodesics, and Parallel Transport

2025-10-20

1. Riemannian Connection on a Riemannian Manifold

Let \((M,g)\) be a Riemannian manifold.

Theorem 1.1Existence and uniqueness of the Riemannian connection

On a Riemannian manifold \(M\), there is a unique connection \(\nabla\) on \(TM\) such that

  1. Symmetry \[ \nabla_X Y - \nabla_Y X = [X,Y] \]
  2. Compatibility with \(g\) \[ X\,g(Y,Z) = g(\nabla_X Y,Z) + g(Y,\nabla_X Z) \] This connection is called the Riemannian connection (or Levi-Civita connection).

1.1 Sketch of the proof

Use (1) and (2) to combine the three expressions \[ X\,g(Y,Z),\quad Y\,g(X,Z),\quad Z\,g(X,Y) \] into a symmetric combination: \[ X\,g(Y,Z) + Y\,g(X,Z) - Z\,g(X,Y) \] Using symmetry and compatibility one can rewrite this as \[ \begin{aligned} X\,g(Y,Z) + Y\,g(X,Z) - Z\,g(X,Y) &= 2\,g(\nabla_X Y,Z) + \text{terms involving only }[\,\cdot,\cdot\,] \end{aligned} \]

Hence we can solve for \(g(\nabla_X Y,Z)\) purely in terms of \(g\) and the Lie bracket \([\,\cdot,\cdot\,]\).
This determines \(\nabla_X Y\) uniquely, and one checks that the resulting \(\nabla\) satisfies (1) and (2).

2. Riemannian Connection in Local Coordinates

Let \((x^1,\dots,x^n)\) be local coordinates, and write \(\partial_i := \dfrac{\partial}{\partial x^i}\).

2.1 Christoffel symbols

Definition 2.1Christoffel symbols

The Christoffel symbols \(\Gamma_{ij}^k\) are the coefficients defined by \[ \nabla_{\partial_i}\partial_j = \Gamma_{ij}^k\,\partial_k \] (Here the \(\Gamma_{ij}^k\) depend on the chosen coordinates and do not form a tensor.)

Let \(g_{jh} = g(\partial_j,\partial_h)\). By compatibility, \[ \begin{aligned} \partial_i g_{jh} &= \partial_i g(\partial_j,\partial_h) \\[4pt] &= g(\nabla_{\partial_i}\partial_j,\partial_h) + g(\partial_j,\nabla_{\partial_i}\partial_h) \\[4pt] &= \Gamma_{ij}^k g_{kh} + \Gamma_{ih}^k g_{jk} \end{aligned} \]

Now write down the three versions obtained by cyclic permutation of \((i,j,h)\): \[ \begin{aligned} \partial_i g_{jh} &= \Gamma_{ij}^k g_{kh} + \Gamma_{ih}^k g_{jk} \\[4pt] \partial_j g_{ih} &= \Gamma_{ji}^k g_{kh} + \Gamma_{jh}^k g_{ik} \\[4pt] \partial_h g_{ij} &= \Gamma_{hi}^k g_{kj} + \Gamma_{hj}^k g_{ik} \end{aligned} \]

Using symmetry \(\Gamma_{ij}^k = \Gamma_{ji}^k\) and combining these three equations, one solves for \(\Gamma_{ij}^k\). In matrix form this gives \[ \boxed{\Gamma_{ij}^k = \tfrac12\,g^{k\ell} \Big( \partial_i g_{j\ell} + \partial_j g_{i\ell} - \partial_\ell g_{ij} \Big)} \] where \((g^{k\ell})\) is the inverse matrix of \((g_{k\ell})\). This is the standard coordinate formula for the Riemannian connection.

3. Example: The Cone in \(\mathbb{R}^3\)

Consider the cone \[ \Sigma = \{(x,y,z)\in\mathbb{R}^3 \mid z = a r\} \] parametrized by \[ \sigma(z,\theta) = (a z\cos\theta,\; a z\sin\theta,\; z) \]

We use coordinates \((z,\theta)\) on \(\Sigma\). Write \[ \partial_z := \frac{\partial}{\partial z},\qquad \partial_\theta := \frac{\partial}{\partial \theta} \]

We will compute \(\nabla_{\partial_\theta}\partial_\theta\) in two ways.

3.1 Geometric computation

First derivatives: \[ \begin{aligned} \sigma_z &= \partial_z\sigma = (a\cos\theta,\; a\sin\theta,\; 1) \\[4pt] \sigma_\theta &= \partial_\theta\sigma = (-a z\sin\theta,\; a z\cos\theta,\; 0) \end{aligned} \]

Second derivative in the \(\theta\)–direction: \[ \sigma_{\theta\theta} = \partial_\theta\sigma_\theta = (-a z\cos\theta,\; -a z\sin\theta,\; 0) \]

This vector \(\sigma_{\theta\theta}\) is not tangent to the cone (it points “towards” the \(z\)–axis).
Let \[ e_1 := \frac{\sigma_z}{\|\sigma_z\|} = \frac{1}{\sqrt{1+a^2}}\,(a\cos\theta,\; a\sin\theta,\; 1) \] be a unit tangent vector along the \(z\)–direction.

The Riemannian connection on \(\Sigma\) is the orthogonal projection of the ambient Euclidean derivative onto \(T\Sigma\), so \[ \nabla_{\partial_\theta}\partial_\theta = \text{projection of }\sigma_{\theta\theta}\text{ onto }T\Sigma = \langle\sigma_{\theta\theta},e_1\rangle\,e_1 \]

A short computation gives \[ \langle\sigma_{\theta\theta},e_1\rangle = -\frac{a^2 z}{1+a^2} \] so \[ \nabla_{\partial_\theta}\partial_\theta = -\frac{a^2 z}{1+a^2}\,e_1 \]

3.2 Christoffel symbols on the cone

First compute the induced metric: \[ \begin{aligned} g_{zz} &= \langle\sigma_z,\sigma_z\rangle = 1+a^2 \\[4pt] g_{z\theta} &= \langle\sigma_z,\sigma_\theta\rangle = 0 \\[4pt] g_{\theta\theta} &= \langle\sigma_\theta,\sigma_\theta\rangle = a^2 z^2 \end{aligned} \]

Thus, in the coordinates \((z,\theta)\), \[ [g_{ij}] = \begin{pmatrix} 1+a^2 & 0 \\ 0 & a^2 z^2 \end{pmatrix} \]

We write \(\partial_1 = \partial_z\), \(\partial_2 = \partial_\theta\).
Then \[ \nabla_{\partial_\theta}\partial_\theta = \Gamma_{22}^i\,\partial_i \]

Using the coordinate formula for the Christoffel symbols, \[ \Gamma_{22}^1 = \tfrac12\,g^{1j} \big(2\,\partial_2 g_{2j} - \partial_j g_{22}\big) \]

Since \(g_{22} = a^2 z^2\) and \(g_{21}=g_{12}=0\), the only non–zero contribution comes from \(j=1\): \[ \begin{aligned} \Gamma_{22}^1 &= \tfrac12\,g^{11}\big(-\partial_1 g_{22}\big) \\[4pt] &= \tfrac12\,\frac{1}{1+a^2} \big(-\partial_z(a^2 z^2)\big) \\[4pt] &= \tfrac12\,\frac{1}{1+a^2} \big(-2 a^2 z\big) \\[4pt] &= -\frac{a^2 z}{1+a^2} \end{aligned} \]

Moreover, \[ \Gamma_{22}^2 = 0 \]

Therefore, \[ \nabla_{\partial_\theta}\partial_\theta = \Gamma_{22}^1\,\partial_z = -\frac{a^2 z}{1+a^2}\,\partial_z \]

This agrees with the geometric computation, once we rewrite \(e_1\) in terms of \(\partial_z\).

Theorem 3.1Submanifold connection

If \(M\subset\mathbb{R}^N\) and \(g\) is the restriction of the Euclidean metric, then the Riemannian connection on \(M\) is obtained by orthogonal projection of the ambient Euclidean derivative onto the tangent spaces of \(M\).

4. Covariant Differentiation Along a Curve

4.1 Covariant derivative along a curve

Let \(\gamma:I\to M\) be a smooth curve and \(X\) a vector field along \(\gamma\), meaning \[ X(t)\in T_{\gamma(t)}M \] and \(X(t)\) varies smoothly with \(t\).

Definition 4.1Covariant derivative along \(\gamma\)

The covariant derivative of \(X\) along \(\gamma\) is \[ D_t X := \nabla_{\dot\gamma}X(t)\in T_{\gamma(t)}M \]

4.2 Coordinate expression

In local coordinates, write \[ \gamma(t) = (x^1(t),\dots,x^n(t)),\qquad X(t) = a^i(t)\,\partial_i \] and \[ \dot\gamma = \dot x^i\,\partial_i \]

Compute: \[ \begin{aligned} D_t X &= \nabla_{\dot\gamma}(a^k\partial_k) \\[4pt] &= \underbrace{\dot a^k\partial_k}_{\text{derivative of coefficients}} + a^k\nabla_{\dot\gamma}\partial_k \\[4pt] &= \dot a^k\partial_k + a^k \dot x^j \nabla_{\partial_j}\partial_k \\[4pt] &= \dot a^k\partial_k + a^k \dot x^j \Gamma_{jk}^i \partial_i \\[4pt] &= \big(\dot a^i + \dot x^j a^k \Gamma_{jk}^i\big)\partial_i \end{aligned} \]

So the coordinate form is \[ D_t X = \big(\dot a^i + \dot x^j a^k \Gamma_{jk}^i\big)\partial_i \]

4.3 Geodesics

Definition 4.2Geodesic

A curve \(\gamma\) is a geodesic if its covariant acceleration vanishes: \[ D_t\dot\gamma = 0 \]

In coordinates, \(\dot\gamma = \dot x^i\partial_i\), so using the formula for \(D_t\) we get \[ D_t\dot\gamma = \big(\ddot x^i + \dot x^j\dot x^k\Gamma_{jk}^i\big)\partial_i \] Thus \(\gamma\) is a geodesic iff \[ \ddot x^i + \dot x^j\dot x^k\Gamma_{jk}^i = 0 \quad\text{for }i=1,\dots,n \] This is a linear system of second–order ODEs for the coordinates \(x^i(t)\).

Theorem 4.3Existence and uniqueness of geodesics

For any point \(\gamma(0)\in M\) and initial velocity \(\dot\gamma(0)\in T_{\gamma(0)}M\), there exists a unique geodesic \(\gamma(t)\) solving the geodesic equation with these initial conditions.

5. Parallel Transport

5.1 Parallel vector fields

Definition 5.1Parallel vector field along a curve

A vector field \(X\) along a curve \(\gamma\) is parallel if \[ D_t X = 0 \]

In coordinates, if \(X = a^i\partial_i\), then \[ D_t X = 0 \quad\Longleftrightarrow\quad \dot a^i + a^k\dot x^j\Gamma_{jk}^i = 0 \quad\text{for }i=1,\dots,n \] This is a linear first–order system of ODEs for the coefficient functions \(a^i(t)\).

Theorem 5.2Existence and uniqueness of parallel transport

Given a curve \(\gamma\) and an initial vector \(X(0)\in T_{\gamma(0)}M\), there exists a unique parallel vector field \(X(t)\) along \(\gamma\) with \(X(0)\) as initial value.

Geometrically, parallel transport along \(\gamma\) gives a map between tangent spaces: \[ T_{\gamma(t_0)}M \longrightarrow T_{\gamma(t_1)}M \] It “connects’’ the tangent spaces along the curve \(\gamma\) by sliding vectors so that they remain parallel in the sense \(D_t X = 0\).
