4. LU Error Analysis and Row Pivoting

Numerical Methods I — Florian Schaefer. Source: Lecture 04.pdf, pp. 1–8.

4.1 Recap

Gaussian elimination produces elementary lower-triangular matrices \(L_k\). When the required pivots are nonzero,

\[ \underbrace{L_m\cdots L_1A}_{U}x=L_m\cdots L_1b, \qquad A=LU, \qquad L=L_1^{-1}\cdots L_m^{-1}. \]

The matrix \(U\) is upper triangular, and \(L\) is unit lower triangular. The elimination multipliers can be stored below the diagonal in the same array that holds \(U\) on and above the diagonal.

A zero pivot can prevent the factorization even when \(A\) is invertible. A very small pivot can instead produce large intermediate entries and loss of accuracy. This lecture develops the error estimate behind that concern and introduces row pivoting.

4.2 Componentwise Error Analysis for LU

Here \(\epsilon\) denotes machine precision. The notation \(L\) and \(U\) is retained for the computed factors, as on the sheet.

For a matrix \(M\), \(|M|\) denotes its entrywise absolute value. A matrix inequality is interpreted entrywise, and \(|L|\,|U|\) denotes ordinary matrix multiplication:

\[ (|L|\,|U|)_{ik}=\sum_{j=1}^m|L_{ij}|\,|U_{jk}|. \]

TheoremLU error estimate — lecture’s first-order form

Suppose LU factorization terminates without a zero pivot and its operations satisfy the relative rounding-error model. Then \[ A=LU+E, \qquad \boxed{|E|\lesssim m\epsilon\,|L|\,|U|.} \] The estimate is componentwise and is stated to first order in \(\epsilon\).

The factor \(m\epsilon\) is absent from the theorem line on p. 2 but present in the proof on p. 3 and in Lecture 03. It has been restored here. Throughout this section, \(\lesssim\) indicates that the lecture’s higher-order rounding factors are being suppressed; the displayed coefficient is not being asserted as an exact finite-\(\epsilon\) bound.1

4.2.1 Entrywise Relations in Exact Arithmetic

Because \(L\) is unit lower triangular and \(U\) is upper triangular,

\[ A_{ik}=\sum_{j=1}^{\min(i,k)}L_{ij}U_{jk}. \]

For \(i\le k\), isolating the contribution with \(j=i\) gives

\[ \begin{aligned} A_{ik} &=\sum_{j=1}^{i-1}L_{ij}U_{jk} +\underbrace{L_{ii}}_{1}U_{ik},\\ U_{ik} &=A_{ik}-\sum_{j=1}^{i-1}L_{ij}U_{jk}. \end{aligned} \]

For \(i>k\), isolating the contribution with \(j=k\) instead gives2

\[ \begin{aligned} A_{ik} &=\sum_{j=1}^{k-1}L_{ij}U_{jk}+L_{ik}U_{kk},\\ L_{ik} &=\frac{A_{ik}-\displaystyle\sum_{j=1}^{k-1}L_{ij}U_{jk}}{U_{kk}}. \end{aligned} \]

The different upper limits matter: the first relation computes an entry of \(U\); the second computes an entry of \(L\) below the diagonal.

4.2.2 Floating-Point Summation

The lecture uses the following first-order description of a computed dot product, referring to it as “HW2”:

\[ \operatorname{fl}\!\left(\sum_{i=1}^m x_i y_i\right) =\sum_{i=1}^m x_i y_i(1+\delta_i), \qquad |\delta_i|\lesssim m\epsilon. \]

Here \(\operatorname{fl}\) marks a computed quantity; it is inserted to distinguish the floating-point evaluation from the exact sum. The sheet does not include the homework problem itself or its proof.

4.2.3 Error in an Entry of U

For \(i\le k\), the sheet models the computed entry as

\[ U_{ik} =\left( A_{ik}-\sum_{j=1}^{i-1}L_{ij}U_{jk}(1+\delta_j') \right)(1+\delta'), \]

where, to the order retained in the lecture,

\[ |\delta_j'|\lesssim(i-1)\epsilon, \qquad |\delta'|\le\epsilon. \]

Rearrange this identity using \(L_{ii}=1\):

\[ \begin{aligned} A_{ik} &=\frac{L_{ii}U_{ik}}{1+\delta'} +\sum_{j=1}^{i-1}L_{ij}U_{jk}(1+\delta_j')\\ &=\sum_{j=1}^{i}L_{ij}U_{jk} +\underbrace{\sum_{j=1}^{i}L_{ij}U_{jk}\delta_j}_{E_{ik}}, \end{aligned} \]

where

\[ \delta_j=\delta_j'\quad(j<i), \qquad 1+\delta_i=\frac{1}{1+\delta'}. \]

In particular,

\[ \delta_i=-\frac{\delta'}{1+\delta'}, \qquad |\delta_i|\le\frac{\epsilon}{1-\epsilon} \quad\text{when }\epsilon<1. \]

The last identity makes explicit why the reciprocal rounding factor is only of size \(\epsilon\) to first order. Using a common first-order bound for the coefficients,3

\[ \begin{aligned} |E_{ik}| &=\left|\sum_{j=1}^{i}L_{ij}U_{jk}\delta_j\right|\\ &\le\sum_{j=1}^{i}|L_{ij}|\,|U_{jk}|\,|\delta_j|\\ &\lesssim m\epsilon\sum_{j=1}^{i}|L_{ij}|\,|U_{jk}|\\ &=m\epsilon\,(|L|\,|U|)_{ik}. \end{aligned} \]

The final equality uses the triangular zeros: terms with \(j>i\) vanish.

4.2.4 Error in an Entry of L

For \(i>k\), there is also a rounding error from division by \(U_{kk}\). The sheet writes the computed multiplier in the form

\[ L_{ik} =(1+\delta'') \frac{(1+\delta')\left( A_{ik}-\displaystyle\sum_{j=1}^{k-1}L_{ij}U_{jk}(1+\delta_j') \right)}{U_{kk}}, \qquad |\delta''|\le\epsilon. \]

Rearranging yields

\[ \begin{aligned} A_{ik} &=\frac{L_{ik}U_{kk}}{(1+\delta')(1+\delta'')} +\sum_{j=1}^{k-1}L_{ij}U_{jk}(1+\delta_j')\\ &=\sum_{j=1}^{k}L_{ij}U_{jk}+E_{ik}. \end{aligned} \]

The same first-order reasoning gives

\[ |E_{ik}|\lesssim m\epsilon\,(|L|\,|U|)_{ik}. \]

Combining the entries of \(L\) and \(U\) gives

\[ \boxed{A=LU+E,\qquad |E|\lesssim m\epsilon\,|L|\,|U|.} \]

The estimate draws attention to the size of the computed factors. Small pivots can create large factors, making this error bound large even when the original entries of \(A\) are modest.

4.3 Pivots and Intermediate Products

Consider the \(k\)-th step of elimination. Let \(\widetilde{A}\) denote the current matrix in the still-active part of the calculation, after the preceding steps. In the packed storage diagram, the earlier columns already contain the multipliers belonging to \(L\), and the completed rows belong to \(U\).

DefinitionPivot

At step \(k\), the current entry \(\widetilde{A}_{kk}\) used to divide the entries below it is the pivot.

The new entries are

\[ L_{ik}=\frac{\widetilde{A}_{ik}}{\widetilde{A}_{kk}},\qquad i>k, \qquad U_{kj}=\widetilde{A}_{kj},\qquad j\ge k. \]

The trailing update involves products

\[ L_{ik}U_{kj} =\frac{\widetilde{A}_{ik}\widetilde{A}_{kj}}{\widetilde{A}_{kk}}. \]

Consequently, the largest magnitude of such a product in the active trailing block is4

\[ \max_{i,j>k}|L_{ik}U_{kj}| = \frac{\displaystyle\max_{i,j>k} |\widetilde{A}_{ik}\widetilde{A}_{kj}|} {|\widetilde{A}_{kk}|}. \]

A small denominator can produce large intermediate quantities. We therefore need to avoid zero pivots and would also like to avoid small pivots.

4.4 Row Pivoting

The strategy developed in the lecture chooses the largest-magnitude entry in the active part of the current column:

\[ \kappa\in\operatorname*{arg\,max}_{i=k,\ldots,m} |\widetilde{A}_{ik}|. \]

Swap rows \(k\) and \(\kappa\), so that the selected entry becomes the pivot. Write \(P_k\) for the permutation matrix performing that row swap.

The step is now

\[ \widetilde{A} \xrightarrow{\;P_k\;} P_k\widetilde{A} \xrightarrow{\;L_k\;} L_kP_k\widetilde{A}. \]

The diagram on the sheet compares this with elimination directly from the original diagonal entry.

If the chosen pivot is nonzero, its maximal magnitude in the active column gives

\[ |L_{ik}| =\frac{|(P_k\widetilde{A})_{ik}|} {|(P_k\widetilde{A})_{kk}|} \le1, \qquad i>k. \]

Thus this pivot choice prevents large elimination multipliers caused by selecting a small entry when a larger one is available in the same column. This observation by itself is not a bound on all entries of \(U\).

4.5 Commuting Permutations Past Elimination Matrices

With row permutations interleaved with elimination, the overall transformation is

\[ U=L_mP_m\cdots L_1P_1A. \]

To recover a factorization with one permutation matrix, we need to move the permutations to the right while keeping track of their effect on the elementary matrices.

Let \(P_\ell\) be a later row swap, with \(\ell>k\). Since a single row swap is its own inverse,

\[ P_\ell^2=I. \]

Insert this identity:

\[ \begin{aligned} P_\ell L_k &=P_\ell L_k\underbrace{P_\ell P_\ell}_{I}\\ &=\underbrace{(P_\ell L_kP_\ell)}_{\text{permute rows and columns of }L_k}\,P_\ell. \end{aligned} \]

The source illustrates this conjugation by swapping both a row and a column of \(L_k\). Because this later swap acts only on indices greater than \(k\), the \(k\)-th coordinate vector is unchanged. Using \(L_k=I-\ell_ke_k^*\),

\[ P_\ell L_kP_\ell =I-(P_\ell\ell_k)e_k^*. \]

The matrix remains elementary lower triangular; its multiplier entries below row \(k\) have simply been reordered.

Repeating this rearrangement gives the factorization implicit in the lecture’s diagrams:5

\[ \begin{aligned} U &=\widetilde{L}_m\cdots\widetilde{L}_1 \underbrace{P_m\cdots P_1}_{P}A,\\ PA &=\underbrace{(\widetilde{L}_m\cdots\widetilde{L}_1)^{-1}}_L U. \end{aligned} \]

Here the tildes distinguish the elementary matrices after their multipliers have been permuted. Therefore,

\[ \boxed{PA=LU.} \]

The matrix \(P\) records all row swaps, \(L\) is unit lower triangular, and \(U\) is upper triangular.

4.6 Updating the Packed Factorization

Suppose the current mathematical elimination state satisfies

\[ L_k\cdots L_1PA=U_k. \]

Here \(U_k\) is the partially eliminated matrix. The implementation additionally stores the earlier multipliers in the positions below its completed diagonal entries.

Apply the next row swap and elimination step:

\[ L_{k+1}P_{k+1}L_k\cdots L_1PA =L_{k+1}P_{k+1}U_k. \]

For each earlier elementary matrix, define

\[ L_j'=P_{k+1}L_jP_{k+1},\qquad j=1,\ldots,k, \qquad P'=P_{k+1}P. \]

Commuting the new permutation to the right gives

\[ \begin{aligned} L_{k+1}L_k'\cdots L_1' \underbrace{P_{k+1}P}_{P'}A &=\underbrace{L_{k+1}P_{k+1}U_k}_{U_{k+1}},\\ L_{k+1}L_k'\cdots L_1'P'A&=U_{k+1}. \end{aligned} \]

This explains an important implementation detail: a row swap must also reorder the multipliers already stored in earlier columns. Swapping the complete rows of the packed array performs both operations at once: it moves the active matrix entries and the previously stored entries of \(L\).

4.7 Algorithm: LU Factorization with Row Pivoting

The sheet initializes \(P=I\) and then, for each column, selects a pivot, swaps the corresponding rows in both \(A\) and \(P\), stores the multipliers, and updates the trailing block.

The following Julia-style transcription assumes that \(A\) is a square floating-point array. The original array is overwritten. The explicit identity-matrix construction and zero-pivot guard are implementation clarifications.6

using LinearAlgebra

m = size(A, 1)
P = Matrix{Int}(I, m, m)

for k in 1:m
    # argmax returns an index local to the active part of the column.
    κ = k - 1 + argmax(abs.(@view A[k:m, k]))

    # Swap complete rows, including multipliers in earlier columns.
    for j in 1:m
        A[κ, j], A[k, j] = A[k, j], A[κ, j]
        P[κ, j], P[k, j] = P[k, j], P[κ, j]
    end

    if iszero(A[k, k])
        error("Zero pivot after row pivoting.")
    end

    for i in (k + 1):m
        A[i, k] /= A[k, k]
    end

    for i in (k + 1):m
        for j in (k + 1):m
            A[i, j] -= A[i, k] * A[k, j]
        end
    end
end

On exit, the strict lower triangle of the stored array contains the off-diagonal entries of \(L\), and the diagonal and upper triangle contain \(U\). The diagonal of \(L\) is understood to consist of ones. In Julia, these factors can be viewed as

L = UnitLowerTriangular(A)
U = UpperTriangular(A)

Both views refer to the packed array. The factorization identity concerns the matrix before it was overwritten:

\[ \boxed{P A_{\mathrm{original}}=LU.} \]
